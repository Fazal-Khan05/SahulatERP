# Notes for later, one file for each step

From Step 21 on, a step writes what it noticed for later into a file of its own here:
`step-21.md`, `step-22.md` and so on. The steps can be built by three people at once
(docs/PARALLEL.md), and three people adding to the end of one file is a conflict every time.

A step's file has, as needed:

- **Later**: what belongs to a later step or to nobody yet, as in `docs/LATER.md`.
- **For the other tracks**: the tables, columns and status changes of this step that another
  track may rely on (and which this track will therefore not rename).
- **Decided by the founder**: decisions made while building, with the date.
- **Questions for a tax adviser**: as in `docs/RATES-REVIEW.md`.

`docs/LATER.md` (Steps 2 to 20) and `docs/RATES-REVIEW.md` stay as they are and are not added to
by a track.
